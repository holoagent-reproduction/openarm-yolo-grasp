# 示例

仅识别和规划：

```bash
python3 scripts/semantic_pick.py --url http://172.16.20.130:8780 start "拿起桌子上的水杯"
```

该命令创建预览任务，不会执行真实运动。

查询任务：

```bash
python3 scripts/semantic_pick.py --url http://172.16.20.130:8780 status <任务ID>
```

该命令读取检测、规划或执行状态。

确认真实任务：

```bash
python3 scripts/semantic_pick.py --url http://172.16.20.130:8780 confirm <任务ID>
```

该命令只对已经以 `--execute` 创建且处于 `wait_confirm` 的任务发送人工确认。
