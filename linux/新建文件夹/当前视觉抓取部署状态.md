## 当前阻塞

`172.16.20.130` 出现 IP 冲突：

- 正确 Ubuntu NUC 的 ping 通常返回 `TTL=64`。
- 冲突设备返回 `TTL=128`，且 SSH 22 端口不可用。

在确认 NUC 实际 IP 前，不应继续远端部署，避免写入错误设备。

1. 在 NUC 本机执行 `hostname -I`，确认实际 IP。
2. 重新上传 `semantic_grasp.launch.py`。
3. 在 NUC 新视觉包内保存旧文件备份并部署新文件。
4. 只构建 `openarm_vision_grasp`。
5. 启动独立双相机。
6. 用 `start_cameras:=false allow_motion:=false show_ui:=false` 启动语义安全预览链路。
7. 验证 YOLOE 检测叠加图、三维目标和 TF；不执行机械臂运动。
